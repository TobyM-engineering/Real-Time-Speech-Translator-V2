# Media

Photos and video of the finished build, referenced from the root [`README.md`](../README.md).

## Naming convention

Drop files in with these exact names and they will appear in the places already prepared for them — the markup and captions are written, commented out, at the matching point in the README.

| Filename | Shows |
|---|---|
| `translator-demo.mp4` | The device translating live: one person speaks, the other's earbud answers a couple of seconds later |
| `board_stack.jpg` | The assembled stack laid flat — UPS HAT, Pi 5, display |
| `worn.jpg` | Both transmitters clipped on in wearing position, black and grey windscreens visible |
| `screen.jpg` | The screen mid-conversation, both halves showing their own language |

Anything else is free-form. JPEG for stills, MP4 for video.

Wiring and layout diagrams belong in [`../hardware/`](../hardware/); the SVG figures used throughout the documentation live in [`../docs/diagrams/`](../docs/diagrams/).
