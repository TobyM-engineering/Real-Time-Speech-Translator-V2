# Media

Photographs, video and wiring diagrams of the build, referenced from the root [`README.md`](../README.md) and from [`../docs/hardware.md`](../docs/hardware.md).

## Naming convention

Drop files in with these exact names and they appear in the places already prepared for them — the markup and captions are written, commented out, at the matching point in each document.

| Filename | Shows |
|---|---|
| `translator-demo.mp4` | The device translating live: one person speaks, the other's earbud answers a couple of seconds later |
| `board_stack.jpg` | The assembled stack laid flat — UPS HAT, Pi 5, display |
| `worn.jpg` | Both transmitters clipped on in wearing position, black and grey windscreens visible |
| `screen.jpg` | The screen mid-conversation, both halves showing their own language |
| `wiring_diagram.png` | The full wiring: display ribbon to `CAM/DISP 0`, display power on GPIO pins 2 and 6, fan header, receiver on a black USB 2.0 port, mains into the UPS HAT's USB-C input |

Anything else is free-form. JPEG for photographs, PNG for diagrams, MP4 for video.

The SVG figures used throughout the documentation are generated, not photographed, and live in [`../docs/diagrams/`](../docs/diagrams/).
