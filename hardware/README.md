# Hardware Diagrams

Wiring photographs and layout diagrams for the physical build.

The written wiring list is in [`../docs/hardware.md`](../docs/hardware.md), and the layer-by-layer stack figure is [`../docs/diagrams/physical-stack.svg`](../docs/diagrams/physical-stack.svg).

## Naming convention

| Filename | Shows |
|---|---|
| `wiring_diagram.png` | The full wiring: display ribbon to `CAM/DISP 0`, display power on GPIO pins 2 and 6, fan header, receiver on a black USB 2.0 port, mains into the UPS HAT's USB-C input |
| `stack_layout.png` | How the boards physically stack, and the clearances the down-angled USB adapter is chosen for |

PNG for diagrams. Photographs of the build itself go in [`../media/`](../media/) instead.
